## ✅ Pré-requisitos

Antes de rodar o projeto, verifique se você tem as seguintes ferramentas instaladas:

- [Node.js](https://nodejs.org/en/download/) - versão **18.19.1** ou superior
- [npm](https://nodejs.org/en/download/package-manager) - versão **8.19.1** ou superior
- [Angular CLI](https://angular.dev/) - versão **17.3.11** ou superior

Verifique as versões com:

```bash
node -v
npm -v
ng version





# 1. Instale o Angular CLI globalmente (caso não tenha)
npm install -g @angular/cli

# 2. Clone o repositório do projeto
git clone https://github.com/ssergiofeitosa/Projeto-Restic---Burguer-Mania.git

# 3. Acesse a pasta do projeto
cd seu-repositorio

# 4. Instale as dependências do projeto
npm install

# 5. Rode o servidor de desenvolvimento
ng serve

# 6. Acesse no navegador
http://localhost:4200/
